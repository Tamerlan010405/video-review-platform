# Video Review Platform

Платформа для ревью чернового монтажа: загружаешь видео, команда смотрит его в браузере и оставляет
комментарии, привязанные к конкретному кадру, продюсер переводит монтаж в статус «На правках» или «Принято».

## Запуск

```bash
npm run install:all   # зависимости корня, backend и frontend
npm run dev           # API на :4000 и фронтенд на http://127.0.0.1:5173
```

Другие команды: `npm test` (тесты API), `npm run typecheck`, `npm run build`.

## Стек

- **Frontend**: React 19, TypeScript (strict), Mantine 9, React Router, CSS Modules, Vite.
- **Backend**: Node.js, Express 5, TypeScript, zod (валидация), multer (загрузка файлов), хранение в JSON-файле.

## REST API (`/api/v1`)

Пользователь определяется заголовком `X-User-Id` (демо-авторизация: `u-editor`, `u-reviewer`, `u-producer`).
Ошибки приходят единым форматом `{ "error": { "code", "message", "field?" } }`.

| Метод | Путь | Описание | Права |
|---|---|---|---|
| GET | `/projects` | список монтажей со счётчиками замечаний | все |
| GET | `/projects/:id` | один монтаж | все |
| POST | `/projects` | загрузка монтажа (`multipart/form-data`: title, description, fps, poster, file) | все |
| PATCH | `/projects/:id/status` | смена статуса | продюсер |
| DELETE | `/projects/:id` | удаление монтажа и файла | продюсер или автор |
| GET | `/projects/:id/video` | видео с поддержкой `Range` (перемотка) | без авторизации* |
| GET | `/projects/:id/comments` | комментарии монтажа | все |
| POST | `/projects/:id/comments` | комментарий к кадру | все |
| PATCH | `/comments/:id` | отметить исправленным (`resolved`) | все |
| DELETE | `/comments/:id` | удалить комментарий | автор или продюсер |

\* тег `<video>` не умеет слать свои заголовки; в проде для этого нужны подписанные ссылки или cookie.

Коды ответов: `200/201/204`, `400` (валидация), `401` (нет пользователя), `403` (нет прав), `404`, `413` (файл слишком большой).

## Работа с API на фронтенде

- Типизированный клиент `src/api/client.ts`: единая обработка ошибок (`ApiError` со статусом, кодом и полем), сетевые сбои, `204 No Content`.
- Отмена запросов через `AbortController` при уходе со страницы (`useReview`).
- Загрузка файла с прогрессом через `XMLHttpRequest` (`uploadForm`), ошибки сервера показываются у нужного поля формы.
- Состояния загрузки, ошибок и пустого списка на каждом экране.
- Dev-прокси Vite (`/api` → `:4000`), адрес API настраивается через `VITE_API_URL`.

## Возможности

- **Покадровая навигация**: ← / → — один кадр, Shift + ← / → — секунда, Пробел — пауза, скорость 0.5×–2×.
- **Комментарии к кадру**: таймкод `ЧЧ:ММ:СС:КК`, миниатюра кадра, клик по комментарию или пину на таймлайне перематывает на этот кадр.
- **Таймлайн** написан с нуля: линейка, перетаскивание, подсказка, пины комментариев.
- **Роли и статусы**: монтажёр / ревьюер / продюсер (переключатель в шапке), статус меняет только продюсер, есть история.
- **Минималистичный интерфейс**: нейтральная палитра с одним синим акцентом, без теней и иконок, шрифты Inter Tight и Inter.
  Токены — в `frontend/src/global.css`, тема Mantine — в `frontend/src/App.tsx`.

## Заметки

- Данные бэкенда лежат в `backend/data` (`db.json` и загруженные видео). Удалите папку — база пересоздастся с демо-проектами.
- Демо-проекты используют видео по URL (Big Buck Bunny, MP4/H.264), нужен интернет и браузер с H.264.
- Частота кадров не читается из файла, поэтому задаётся при загрузке.
